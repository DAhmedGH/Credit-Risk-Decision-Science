## Finding: missing accepted inputs break Phase 4 routing (medium, resolved)

It also int-converted blank audit fields, although Phase 1 allows missing demographics. Both valid cases caused a hard error before any mappings/diagnostics could run. Synthetic reproduction: 120 records all accepted by `validate_records`; blank April bill produced `ValueError Financial fingerprint values must be finite`; missing sex produced `ValueError invalid literal for int() with base 10: ''`. The original reproduction is preserved in `/tmp/scientific-audit-missing.py`.

Fixed financial conversion to retain None before fingerprinting and reject any explicit nonfinite literal; audit blanks remain None. No downstream explanation change required: missing categorical audits map to unknown and missing age to the unknown band. Four new parametrized regression cases in `tests/test_audit_partition_inputs.py` verify group/ID/outcome alignment, all-missing financial columns and predictor conversion, missing demographics through descriptive slices, and nonfinite rejection. Targeted suite (new tests + Phase 4 calibration and explanation tests): **27 passed**, no warnings, 15.17 seconds. Ruff on changed files passed.
