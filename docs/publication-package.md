# Source distribution and scientific attachments

This source distribution includes maintained Python modules, SQL, configuration,
locked dependencies, fixture tests, synthetic scoring examples, CI, Docker and
technical documentation. Compact results and selected provenance are included.
Historical scientific artifacts retain their original hashes; presentation copies
of prose do not replace their accepted bytes.

Local setup notes and historical execution attachments are excluded. Original evidence remains in the private working repository
and accepted-source archive. Public validation summaries retain useful findings,
actual checks, measured results and limitations without replacing original receipts.

The trusted private 174-file payload contains the frozen bundle, its required
review evidence, original inputs, saved predictions and evaluation snapshots.
Keep it outside public hosting. Exact historical replay additionally requires the
complete private accepted-source archive; maintained-source scoring uses this
checkout and the unchanged payload. A Git clone alone supports fixture checks,
but cannot score without that payload. See [restoration and scoring](reproduction-phase5.md).

The source distribution has a new local Git history. Historical source commits in
scientific manifests identify the original private evidence, rather than revisions
in this distribution. No remote is configured and no publication has occurred.
Dataset attribution and required notices are preserved in the source manifest,
data README, design, model card and results.
